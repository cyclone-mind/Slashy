# Product

## Register

product

## Users

People who read a lot on the web (research, docs, articles, foreign-language content) and already have an LLM API key. They sit in a narrow Chrome side panel next to the page, in short bursts, and want a result in two keystrokes. Many read Chinese and English.

## Product Purpose

Slashy turns repeatable prompts into slash commands that run on the page or selection the user is looking at. Success: select text, type `/`, pick a skill, get a streamed answer without copy-pasting anything. Free, open source, bring your own model.

## Brand Personality

Quick, exact, unfussy. A power tool, not a companion: no mascot, no chatty onboarding.

## Anti-references

Generic AI chat UI with purple gradients and sparkle icons; marketing-style empty states; heavy cards-in-cards.

## Design Principles

1. The slash is the product: commands look like commands.
2. Context is always visible: the user must see what will be sent.
3. Stay out of the page: dense, calm, readable at 400px wide.
4. Keys and data stay local; say so where keys are entered.

## Accessibility & Inclusion

Keyboard-complete (slash menu, Enter to run, Backspace removes chip), visible focus rings, WCAG AA contrast in light and dark, reduced-motion respected, CJK-safe font stack.
